# 로어북 매니저

## 1.4.33

- 먼저 등록된 SillyTavern 창 닫기 리스너가 폴더 삭제 이벤트를 선점하는 환경에서도 로어북 창이 유지되도록 보강했습니다.
- 반복 감시는 사용하지 않고 확인창 전후·폴더 저장 직후·클릭 애니메이션 종료 시점에만 닫힘 여부를 확인하며, 기존 스크롤 위치도 복원합니다.

## 1.4.32

- Foldy 폴더 삭제 중 로어북 창 상태를 주기적으로 확인하던 보호 타이머를 제거하여 삭제 시 버벅임을 줄였습니다.
- 폴더 삭제 이벤트를 `window` 캡처 단계에서 먼저 분리해, 드로어 바깥 클릭 및 네이티브 로어북 항목 삭제 동작이 시작되기 전에 차단하도록 변경했습니다.

## 1.4.31

- 1.4.30에서 폴더 삭제 시 드로어 상태 감시와 복구가 반복되어 실리태번이 멈출 수 있던 문제를 수정했습니다.
- DOM 변경 감시를 제거하고, 폴더 삭제 중 실제로 로어북 창이 닫힌 경우에만 제한적으로 복구하도록 변경했습니다.

## 1.4.30

- Foldy 폴더 삭제 클릭이 일부 테마·모바일 환경에서 드로어 바깥 클릭으로 중복 처리되어 월드 인포/로어북 창이 닫히던 문제를 수정했습니다.
- 폴더 삭제가 진행되는 짧은 구간에만 월드 인포의 열림 상태를 보호하며, 일반적인 창 닫기 동작에는 개입하지 않습니다.

## 1.4.11

- 별도 엄격 AI 검증 설정과 추가 검수 호출을 제거하고, 번역 수정 전·후 및 원문 수정 전·후 범위 검사와 구조 보호만 항상 적용
- 첫 부분 반영 결과가 범위·줄 구성·구조 검사에 실패하면 결과를 폐기하고 딱 1회 자동 재생성, 재시도 사유를 알림으로 표시
- 구글 번역 모드에서도 전용 AI 프로필 없이 수정된 번역 구간만 원문 언어로 역번역해 대응 원문 구간에만 반영
- 구글 역번역 원문 언어는 원문 문자 구성을 기준으로 영어·일본어·중국어·한국어 중 자동 판별

## 1.4.10

- 확장 설정에 `빠른 검증`과 `엄격 검증` 추가: 빠른 검증은 추가 AI 호출 없이 범위·구조를 검사하고, 엄격 검증은 독립 AI 프로필로 의미 검수 1회를 추가
- 구글 번역 모드에서도 번역은 구글 방식 그대로 사용하고, 원문 부분 반영과 엄격 검증만 독립 AI 프로필을 사용

- 모바일 한글 조합 입력 중간 상태가 자동 원문 반영되지 않도록 조합 완료 후 반영

## 주요 기능

### 편집
- 모든 SillyTavern 1.18 기본 로어북 기능 유지 — 항목 목록은 SillyTavern 기본 방식 그대로 표시됩니다
- 원문/번역 병렬 편집
- 데스크톱에서는 제목·주입 방식·위치·깊이·순서·발동 확률을 기본 항목 행에 표시
- 모바일에서는 제목과 동작 아이콘만 한 줄에 표시하고, 주입 방식·위치·깊이·순서·발동 확률은 호출 조건 탭에서 편집
- 확장 설정에서 모바일 제목 옆 주입 방식 표시를 켜거나 끌 수 있음 (기본 꺼짐)
- 번역 방식 선택: AI 전용 연결 프로필 또는 구글 번역(무료)
- 확장 설정에서 AI 번역·AI 수정·원문 반영에 사용할 출력 토큰을 512~65,536 범위로 지정 (기본 8,192)
- 긴 원문은 문단·줄·문장 경계로 나누어 구글 번역에 순차 전송하고 실패한 조각만 자동 재시도
- 별도의 연결 프로필을 사용하는 AI 편집·키워드 추천 (구글 번역 모드에서도 이 기능들은 프로필 사용)
- 번역 방식·연결 프로필·언어·추가 지시문은 확장 탭의 '로어북 매니저' 패널에서 관리
- 자동 번역·원문 자동 반영 체크박스는 `로어북 상단` 또는 `확장 탭` 중 원하는 위치에 표시
- AI 번역은 문맥·말투·관계에 맞는 자연스러운 번역을 기본 지시하며, 추가 지시문으로 세부 문체를 덧붙일 수 있음
- 원문을 읽은 AI의 호출 키워드 추천, 재추천, 직접 편집 후 선택 삽입
- 번역본이 없는 항목을 열 때 자동 번역하는 독립 설정
- 원문 변경 시 자동 번역
- 번역 변경 시 이전 번역본과 비교하여 수정한 문단·줄만 원문에 자동 반영 또는 수동 반영
- 원문·번역 `AI로 수정`은 커서가 위치한 문단만 수정하고 나머지 문단은 그대로 유지
- 특수문자로 감싼 제목·마크다운 제목·태그·매크로가 AI 수정 중 삭제되거나 구조가 바뀌면 적용을 중단
- 원문·번역, 호출 조건, 그룹·반복, 연결 필터 탭

### 토큰 계산
- 원문 기준 전체 토큰, 상시 주입 🔵 토큰, 선택 주입 🟢 토큰, 벡터화 🔗 토큰을 각각 표시
- 토큰 통계 영역을 한 줄로 접거나 다시 펼칠 수 있으며 선택 상태를 저장
- 확장 설정에서 모바일 토큰 통계 영역 전체의 표시 여부를 선택할 수 있음 (기본 켜짐)
- 로어북 전환 시 자동으로 항목 수와 토큰을 다시 계산
- 항목별 토큰 캐시를 브라우저에 저장하여, 한 번 계산한 로어북은 새로고침 후에도 즉시 표시 (수정된 항목만 재계산, 최근 40개 로어북 유지)
- 원문을 수정하면 해당 항목만 자동 재계산
- 항목을 켜고 끄면 활성 토큰 합계와 활성 항목 수 즉시 반영

### 항목 목록과 필터
- 데스크톱과 모바일 모두 SillyTavern 기본 항목 목록·페이지네이션을 사용하며, 전용 손잡이로 드래그 정렬 가능
- 전체 / 상시 주입 🔵 / 선택 주입 🟢 / 벡터화 🔗 필터를 전체 로어북 항목에 적용
- 항목 필터를 작고 간결하게 표시하며 한 줄로 접거나 다시 펼칠 수 있음
- 확장 설정에서 모바일 항목 필터 영역 전체의 표시 여부를 선택할 수 있음 (기본 켜짐)
- 모바일/데스크톱 그룹·반복 필드 정렬

### 로어북 백업
- API를 사용하지 않는 로컬 자동 백업
- 로어북 원본 데이터와 해당 로어북 번역본만 포함
- 로어북을 열 때 수정 전 기준본을 만들고, 실제 수정이 저장된 뒤 변경본을 추가로 자동 백업 (같은 내용은 중복 저장 안 함)
- 확장 탭에서 백업 목록 확인·수동 백업·현재 로어북 복원·새 로어북 복원
- 전체 백업 영역과 로어북 종류별 백업 목록을 각각 접기·펼치기
- 백업 JSON 가져오기, 백업 하나 또는 전체 백업을 JSON 파일로 내보내기
- 모든 로어북을 합쳐 최근 20개 보관, 같은 내용 중복 백업 방지, 마지막 수정 3분 후 자동 백업, 계속 수정 중이면 30분마다 중간 안전 백업
- 브라우저 데이터 삭제에 대비하려면 주기적으로 전체 내보내기 권장

임베딩 기능은 포함하지 않습니다. 키워드 추천은 사용자가 결과를 확인하고 삽입을 선택하기 전까지 기본 로어북을 변경하지 않습니다.

## 설치

압축을 해제한 `simple-lorebook` 폴더를 아래 위치에 넣고 SillyTavern을 새로고침합니다.

`SillyTavern/data/default-user/extensions/simple-lorebook`

AI 기능을 사용하려면 SillyTavern의 연결 프로필을 먼저 만들어야 합니다. 이 확장에서 선택한 프로필은 메인 채팅 연결 프로필을 변경하지 않습니다.
