# 로어북 매니저

SillyTavern 1.18용 로어북 UI 확장입니다. 기존 월드 인포 목록·페이지네이션·저장 이벤트를 그대로 사용하고 번역 편집기와 보조 도구만 추가합니다.

## 주요 기능

### 편집
- 모든 SillyTavern 1.18 기본 로어북 기능 유지 — 항목 목록은 SillyTavern 기본 방식 그대로 표시됩니다
- 원문/번역 병렬 편집
- 데스크톱에서는 제목·주입 방식·위치·깊이·순서·발동 확률을 기본 항목 행에 표시
- 모바일에서는 제목과 동작 아이콘만 한 줄에 표시하고, 주입 방식·위치·깊이·순서·발동 확률은 호출 조건 탭에서 편집
- 번역 방식 선택: AI 전용 연결 프로필 또는 구글 번역(무료)
- 확장 설정에서 AI 번역·AI 수정·원문 반영에 사용할 출력 토큰을 512~65,536 범위로 지정 (기본 8,192)
- 긴 원문은 문단·줄·문장 경계로 나누어 구글 번역에 순차 전송하고 실패한 조각만 자동 재시도
- 별도의 연결 프로필을 사용하는 AI 편집·키워드 추천 (구글 번역 모드에서도 이 기능들은 프로필 사용)
- 번역 방식·연결 프로필·언어·추가 지시문은 확장 탭의 '로어북 매니저' 패널에서 관리
- 자동 번역·원문 자동 반영 체크박스는 로어북 검색 줄과 토큰 요약 사이에서 데스크톱·모바일 공통으로 관리
- 원문을 읽은 AI의 호출 키워드 추천, 재추천, 직접 편집 후 선택 삽입
- 번역본이 없는 항목을 열 때 자동 번역하는 독립 설정
- 원문 변경 시 자동 번역
- 번역 변경 시 이전 번역본과 비교하여 수정한 문단·줄만 원문에 자동 반영 또는 수동 반영
- 원문·번역, 호출 조건, 그룹·반복, 연결 필터 탭

### 토큰 계산
- 원문 기준 전체 토큰, 상시 주입 🔵 토큰, 선택 주입 🟢 토큰, 벡터화 🔗 토큰을 각각 표시
- 로어북 전환 시 자동으로 항목 수와 토큰을 다시 계산
- 항목별 토큰 캐시를 브라우저에 저장하여, 한 번 계산한 로어북은 새로고침 후에도 즉시 표시 (수정된 항목만 재계산, 최근 40개 로어북 유지)
- 원문을 수정하면 해당 항목만 자동 재계산
- 항목을 켜고 끄면 활성 토큰 합계와 활성 항목 수 즉시 반영

### 항목 목록과 필터
- 데스크톱과 모바일 모두 SillyTavern 기본 항목 목록·페이지네이션·드래그 정렬 사용
- 전체 / 상시 주입 🔵 / 선택 주입 🟢 / 벡터화 🔗 필터를 전체 로어북 항목에 적용
- 모바일/데스크톱 그룹·반복 필드 정렬

임베딩 기능은 포함하지 않습니다. 키워드 추천은 사용자가 결과를 확인하고 삽입을 선택하기 전까지 기본 로어북을 변경하지 않습니다.

## 설치

압축을 해제한 `simple-lorebook` 폴더를 아래 위치에 넣고 SillyTavern을 새로고침합니다.

`SillyTavern/data/default-user/extensions/simple-lorebook`

AI 기능을 사용하려면 SillyTavern의 연결 프로필을 먼저 만들어야 합니다. 이 확장에서 선택한 프로필은 메인 채팅 연결 프로필을 변경하지 않습니다.

## 참고

- 토큰 캐시는 브라우저 localStorage에 저장됩니다. 브라우저 데이터를 지우면 다음에 열 때 한 번 다시 계산합니다.

## 변경 이력

- **1.3.13** — 확장 설정에 AI 출력 토큰 입력란 추가(512~65,536, 기본 8,192), AI 번역·AI 수정·번역본의 원문 반영 요청에 적용하며 연결 테스트와 키워드 추천의 짧은 전용 제한은 유지
- **1.3.12** — 확장 설정에서 접힌 로어북 매니저의 토글 화살표가 반대로 표시되던 문제 수정
- **1.3.11** — 번역본 수정 시 이전 동기화 번역과 줄 단위로 비교하여 변경·삽입·삭제된 구간만 AI에 보내고 대응하는 원문 구간만 교체, 문단 대응이 불확실하면 원문 전체를 건드리지 않는 안전장치와 동기화 기준 저장 추가
- **1.3.10** — 긴 원문을 문단·줄·문장 경계 기준 최대 2,200자 묶음으로 분할하여 순차 번역하고, 요청 간격·조각별 2회 재시도·실패 조각 추가 분할·전체 구글 번역 대기열을 적용해 무료 번역의 부분 실패 완화
- **1.3.9** — 브라우저 전체 폭 대신 각 항목 행의 실제 폭과 토글·작업 아이콘 폭을 측정하고, 패널 크기나 아이콘 수가 바뀌면 즉시 일반/컴팩트 헤더를 자동 전환하도록 반응형 배치 보강
- **1.3.8** — 확장 설정의 번역 추가 지시문 필드에 남던 세로 flex 높이를 제거하고, 모바일 연결 필터의 고정 116px 래퍼 높이를 내용 높이로 변경하여 두 빈 공간 제거
- **1.3.7** — 자동 번역·원문 반영 체크박스를 확장 설정에서 제거하고 로어북 검색 줄과 전체 항목 요약 사이로 이동, 연결 필터 바로 아래에 Additional Matching Sources가 오도록 필드 순서 수정
- **1.3.6** — 모바일 호출 조건을 `Strategy·위치·깊이 / 순서·발동 확률` 2행으로 정렬하고 입력 폭 축소, 연결 필터 좌우 열 높이 통일, 요약 순서 변경 및 벡터화 필터 추가
- **1.3.5** — 데스크톱 기본 항목 행에 전체 열 복원 및 열 제목 중앙 정렬, 모바일 제목·아이콘 한 줄 압축과 나머지 필드의 호출 조건 이동, 벡터화 토큰 표시 추가, 번역 추가 지시문 안내 간격 수정

- **1.3.4** — 커스텀 사이드/모바일 항목 탐색창 제거 및 SillyTavern 기본 목록 복원, 선택·상시 주입 필터 추가, 선택·상시 토큰 동시 표시, 주입 방식·위치·깊이·순서·발동 확률을 호출 조건 탭으로 이동, 번역 안내문 위치 정리

- **1.3.2** — 좁은 화면에서 "지금 번역 반영" 버튼이 세로로 표시되던 문제 수정, 확장 탭에 번역 추가 지시문 설정 추가(AI 프로필 모드에서 적용 · 번역 언어는 설정을 자동으로 따르며, 구글 번역은 기계번역이라 지시문 미적용)

- **1.3.1** — 좁은 패널에서 항목 헤더 필드가 이동/복제/삭제 버튼과 겹치던 문제 수정 (필드가 다음 줄로 감기도록 변경)

- **1.3.0** — 설정을 확장 탭으로 이동, 구글 번역(무료) 방식 추가({{매크로}} 보호 포함), 항목 목록을 SillyTavern 기본 방식으로 복귀(내비게이터는 점프 목록), 원문·번역 탭 간소화(토큰·재귀 옵션은 호출 조건 탭으로), 토큰 합계 범위 선택(활성/상시 🔵)
