# 로어북 매니저

## 1.4.6

- 모든 실제 로어북을 각각의 기본 JSON 파일로 묶어 ZIP으로 내보내는 기능 추가
- 체크 목록에서 여러 로어북을 골라 선택한 로어북만 ZIP으로 내보내는 기능 추가
- 일부 로어북을 불러오지 못해도 나머지 파일은 내보내고 실패 항목을 안내

## 1.4.5

- SillyTavern 확장 관리자에서 확장을 정리하거나 삭제하면 저장된 번역본, 로컬 백업, 토큰 캐시와 확장 설정을 자동 삭제
- 확장 탭의 `데이터 관리`에서 번역본만, 백업만, 또는 확장 데이터 전체를 직접 초기화 가능
- Termux 등에서 폴더를 직접 삭제하기 전에 사용할 수 있는 전체 초기화 기능 추가

## 1.4.4

- 백업 보관 한도를 로어북마다 20개에서 모든 로어북 합산 최근 20개로 변경
- 21번째 백업이 생성되면 로어북 종류와 관계없이 가장 오래된 백업부터 자동 삭제

## 1.4.3

- 수정 중 5분마다 백업하던 방식을 제거하고, 마지막 수정 후 3분간 추가 수정이 없을 때 변경본 1개 저장
- 수정이 30분 이상 계속될 때만 중간 안전본을 저장한 뒤 새로운 작업 구간 시작
- 자동 백업을 끄면 대기 중인 3분·30분 타이머도 즉시 취소

## 1.4.2

- 백업 묶음의 접힌 줄에는 로어북 제목과 오른쪽 펼치기 화살표만 표시하고, 내부 백업 목록은 펼치기 전까지 강제로 숨김
- SillyTavern의 초기화·목록 갱신용 프로그램식 로어북 선택 이벤트를 열기로 오인하지 않도록 차단
- 월드 인포 창을 실제로 열거나 로어북 선택기를 직접 조작했을 때만 열기 기준 백업 생성

## 1.4.1

- 로어북을 열거나 자동 백업을 켤 때 현재 상태를 즉시 기준 백업하며, 이후 실제 수정 저장도 계속 자동 백업
- 동일 내용은 중복 저장하지 않고 수정 후 자동 백업에는 기존 5분 간격을 유지
- 확장 탭의 전체 로어북 백업 영역과 로어북 종류별 백업 묶음을 각각 독립적으로 접고 펼칠 수 있도록 정리

## 1.4.0

- 로어북과 해당 로어북의 번역본만 브라우저 IndexedDB에 자동 백업하는 기능 추가 (API 호출·크레딧 사용 없음)
- 실제 저장 뒤 변경된 내용만 백업하고 로어북별 최소 5분 간격·최근 20개 보관·동일 내용 중복 방지
- 확장 탭에서 백업 시간·항목 수·종류를 확인하고 현재 로어북 복원·새 로어북 복원·JSON 가져오기·개별 내보내기·전체 묶음 내보내기 지원
- 현재 로어북을 덮어쓰기 전에 복원 직전 안전 백업을 자동 생성
- 채팅·캐릭터 카드·페르소나·연결 프로필·API 키·토큰 캐시는 백업 대상에서 제외

## 1.3.37

- 주입 방식 변경 뒤 자동으로 `world_refresh`를 누르던 복구 경로를 완전히 제거해 항목 전체 접힘과 기본 로어북 UI 순간 노출 방지
- Strategy·위치·깊이·순서·발동 확률은 기존 네이티브 입력을 유지한 채 해당 항목 안에서만 최대 5회 재탐색
- 호출 조건 탭과 바깥 drawer의 마지막 실제 상태를 보존해 저장 중 DOM이 잠깐 숨겨져도 최상단 설정 줄을 안전 보관 영역으로 보내지 않음
- DOM 보강을 다음 화면 그리기 전에 한 번만 실행해 로어북 목록 깜빡임과 불필요한 반복 렌더 감소

- 확장에서 추가한 별도 드래그 손잡이와 포인터 드래그 연결을 제거
- 중복 손잡이를 자동 정리하고 SillyTavern 기본 `☰` 드래그 손잡이 하나만 사용
- 순서 저장·모바일 지연 드래그를 포함한 SillyTavern 기본 sortable 동작을 그대로 사용

- 드래그 손잡이에서 실리태번 기본 아이콘과 확장 아이콘이 함께 보이던 중복을 제거
- 배경 없는 연한 가로줄 3개 모양 하나로 통일하고, 마우스를 올리거나 실제 드래그할 때만 조금 진하게 표시

- 데스크톱과 모바일 항목 제목 왼쪽에 전용 드래그 손잡이 추가
- 데스크톱은 손잡이를 바로 끌고, 모바일은 손잡이를 약 0.3초 길게 누른 뒤 끌어서 현재 페이지의 순서를 변경
- 검색·필터·페이지네이션 상태에서는 보이는 항목이 원래 가지고 있던 `displayIndex` 자리만 서로 교환해 다른 페이지 항목의 순서가 밀리지 않도록 저장
- 다른 정렬 방식에서 끌기 시작하면 저장 후 SillyTavern의 사용자 지정 정렬로 자동 전환
- 제목 입력, 접기, 활성화, 복제, 삭제 버튼에서는 드래그가 시작되지 않음

- 1.3.32에서 상태 선택 직후 네이티브 필드를 다른 부모로 옮기던 처리를 제거해 모바일에서 호출 조건 행이나 drawer가 한 번 만에 숨는 문제 수정
- 주입 방식·위치 같은 메타데이터 저장 시에는 원문 해시가 바뀌지 않은 한 전체 토큰 계산을 다시 시작하지 않고 합계만 즉시 갱신하도록 최적화
- 열린 항목 강제 새로고침 금지, 닫은 뒤 필터 1회 갱신, stale 편집기 복구는 유지

SillyTavern 1.18용 로어북 UI 확장입니다. 기존 월드 인포 목록·페이지네이션·저장 이벤트를 그대로 사용하고 번역 편집기와 보조 도구만 추가합니다.

## 주요 기능

### 편집
- 모든 SillyTavern 1.18 기본 로어북 기능 유지 — 항목 목록은 SillyTavern 기본 방식 그대로 표시됩니다
- 원문/번역 병렬 편집
- 데스크톱에서는 제목·주입 방식·위치·깊이·순서·발동 확률을 기본 항목 행에 표시
- 모바일에서는 제목과 동작 아이콘만 한 줄에 표시하고, 주입 방식·위치·깊이·순서·발동 확률은 호출 조건 탭에서 편집
- 확장 설정에서 모바일 제목 옆 주입 방식 표시를 켜거나 끌 수 있음 (기본 꺼짐)
- 번역 방식 선택: AI 전용 연결 프로필 또는 구글 번역(무료)
- 확장 설정에서 AI 번역·AI 수정·원문 반영에 사용할 출력 토큰을 512~65,536 범위로 지정 (기본 8,192)
- 긴 원문은 문단·줄·문장 경계로 나누어 구글 번역에 순차 전송하고 실패한 조각만 자동 재시도
- 별도의 연결 프로필을 사용하는 AI 편집·키워드 추천 (구글 번역 모드에서도 이 기능들은 프로필 사용)
- 번역 방식·연결 프로필·언어·추가 지시문은 확장 탭의 '로어북 매니저' 패널에서 관리
- 자동 번역·원문 자동 반영 체크박스는 `로어북 상단` 또는 `확장 탭` 중 원하는 위치에 표시
- AI 번역은 문맥·말투·관계에 맞는 자연스러운 번역을 기본 지시하며, 추가 지시문으로 세부 문체를 덧붙일 수 있음
- 원문을 읽은 AI의 호출 키워드 추천, 재추천, 직접 편집 후 선택 삽입
- 번역본이 없는 항목을 열 때 자동 번역하는 독립 설정
- 원문 변경 시 자동 번역
- 번역 변경 시 이전 번역본과 비교하여 수정한 문단·줄만 원문에 자동 반영 또는 수동 반영
- 원문·번역, 호출 조건, 그룹·반복, 연결 필터 탭

### 토큰 계산
- 원문 기준 전체 토큰, 상시 주입 🔵 토큰, 선택 주입 🟢 토큰, 벡터화 🔗 토큰을 각각 표시
- 토큰 통계 영역을 한 줄로 접거나 다시 펼칠 수 있으며 선택 상태를 저장
- 확장 설정에서 모바일 토큰 통계 영역 전체의 표시 여부를 선택할 수 있음 (기본 켜짐)
- 로어북 전환 시 자동으로 항목 수와 토큰을 다시 계산
- 항목별 토큰 캐시를 브라우저에 저장하여, 한 번 계산한 로어북은 새로고침 후에도 즉시 표시 (수정된 항목만 재계산, 최근 40개 로어북 유지)
- 원문을 수정하면 해당 항목만 자동 재계산
- 항목을 켜고 끄면 활성 토큰 합계와 활성 항목 수 즉시 반영

### 항목 목록과 필터
- 데스크톱과 모바일 모두 SillyTavern 기본 항목 목록·페이지네이션을 사용하며, 전용 손잡이로 드래그 정렬 가능
- 전체 / 상시 주입 🔵 / 선택 주입 🟢 / 벡터화 🔗 필터를 전체 로어북 항목에 적용
- 항목 필터를 작고 간결하게 표시하며 한 줄로 접거나 다시 펼칠 수 있음
- 확장 설정에서 모바일 항목 필터 영역 전체의 표시 여부를 선택할 수 있음 (기본 켜짐)
- 모바일/데스크톱 그룹·반복 필드 정렬

### 로어북 백업
- API를 사용하지 않는 로컬 자동 백업
- 로어북 원본 데이터와 해당 로어북 번역본만 포함
- 로어북을 열 때 수정 전 기준본을 만들고, 실제 수정이 저장된 뒤 변경본을 추가로 자동 백업 (같은 내용은 중복 저장 안 함)
- 확장 탭에서 백업 목록 확인·수동 백업·현재 로어북 복원·새 로어북 복원
- 전체 백업 영역과 로어북 종류별 백업 목록을 각각 접기·펼치기
- 백업 JSON 가져오기, 백업 하나 또는 전체 백업을 JSON 파일로 내보내기
- 모든 로어북을 합쳐 최근 20개 보관, 같은 내용 중복 백업 방지, 마지막 수정 3분 후 자동 백업, 계속 수정 중이면 30분마다 중간 안전 백업
- 브라우저 데이터 삭제에 대비하려면 주기적으로 전체 내보내기 권장

임베딩 기능은 포함하지 않습니다. 키워드 추천은 사용자가 결과를 확인하고 삽입을 선택하기 전까지 기본 로어북을 변경하지 않습니다.

## 설치

압축을 해제한 `simple-lorebook` 폴더를 아래 위치에 넣고 SillyTavern을 새로고침합니다.

`SillyTavern/data/default-user/extensions/simple-lorebook`

AI 기능을 사용하려면 SillyTavern의 연결 프로필을 먼저 만들어야 합니다. 이 확장에서 선택한 프로필은 메인 채팅 연결 프로필을 변경하지 않습니다.
