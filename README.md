# 로어북 매니저

SillyTavern 1.18용 로어북 UI 확장입니다. 기존 월드 인포 목록·페이지네이션·저장 이벤트를 그대로 사용하고 번역 편집기와 보조 도구만 추가합니다.

## 주요 기능

### 편집
- 모든 SillyTavern 1.18 기본 로어북 기능 유지 — 항목 목록은 SillyTavern 기본 방식 그대로 표시됩니다
- 원문/번역 병렬 편집 (처음 열면 제목·원문·번역만 표시하고, 주입 방식·위치·깊이·순서·발동 확률은 호출 조건 탭에서 편집)
- 번역 방식 선택: AI 전용 연결 프로필 또는 구글 번역(무료)
- 별도의 연결 프로필을 사용하는 AI 편집·키워드 추천 (구글 번역 모드에서도 이 기능들은 프로필 사용)
- 설정은 확장 탭(Extensions)의 '로어북 매니저' 패널에서 관리
- 원문을 읽은 AI의 호출 키워드 추천, 재추천, 직접 편집 후 선택 삽입
- 번역본이 없는 항목을 열 때 자동 번역하는 독립 설정
- 원문 변경 시 자동 번역
- 번역 변경 시 원문 자동 반영 또는 수동 반영
- 원문·번역, 호출 조건, 그룹·반복, 연결 필터 탭

### 토큰 계산
- 원문 기준 전체 토큰, 선택 주입 🟢 토큰, 상시 주입 🔵 토큰을 한 줄에 각각 표시
- 로어북 전환 시 자동으로 항목 수와 토큰을 다시 계산
- 항목별 토큰 캐시를 브라우저에 저장하여, 한 번 계산한 로어북은 새로고침 후에도 즉시 표시 (수정된 항목만 재계산, 최근 40개 로어북 유지)
- 원문을 수정하면 해당 항목만 자동 재계산
- 항목을 켜고 끄면 활성 토큰 합계와 활성 항목 수 즉시 반영

### 항목 목록과 필터
- 데스크톱과 모바일 모두 SillyTavern 기본 항목 목록·페이지네이션·드래그 정렬 사용
- 전체 / 선택 주입 🟢 / 상시 주입 🔵 필터를 전체 로어북 항목에 적용
- 모바일/데스크톱 그룹·반복 필드 정렬

임베딩 기능은 포함하지 않습니다. 키워드 추천은 사용자가 결과를 확인하고 삽입을 선택하기 전까지 기본 로어북을 변경하지 않습니다.

## 설치

압축을 해제한 `simple-lorebook` 폴더를 아래 위치에 넣고 SillyTavern을 새로고침합니다.

`SillyTavern/data/default-user/extensions/simple-lorebook`

AI 기능을 사용하려면 SillyTavern의 연결 프로필을 먼저 만들어야 합니다. 이 확장에서 선택한 프로필은 메인 채팅 연결 프로필을 변경하지 않습니다.

## 참고

- 토큰 캐시는 브라우저 localStorage에 저장됩니다. 브라우저 데이터를 지우면 다음에 열 때 한 번 다시 계산합니다.

## 변경 이력

- **1.3.4** — 커스텀 사이드/모바일 항목 탐색창 제거 및 SillyTavern 기본 목록 복원, 선택·상시 주입 필터 추가, 선택·상시 토큰 동시 표시, 주입 방식·위치·깊이·순서·발동 확률을 호출 조건 탭으로 이동, 번역 안내문 위치 정리

- **1.3.2** — 좁은 화면에서 "지금 번역 반영" 버튼이 세로로 표시되던 문제 수정, 확장 탭에 번역 추가 지시문 설정 추가(AI 프로필 모드에서 적용 · 번역 언어는 설정을 자동으로 따르며, 구글 번역은 기계번역이라 지시문 미적용)

- **1.3.1** — 좁은 패널에서 항목 헤더 필드가 이동/복제/삭제 버튼과 겹치던 문제 수정 (필드가 다음 줄로 감기도록 변경)

- **1.3.0** — 설정을 확장 탭으로 이동, 구글 번역(무료) 방식 추가({{매크로}} 보호 포함), 항목 목록을 SillyTavern 기본 방식으로 복귀(내비게이터는 점프 목록), 원문·번역 탭 간소화(토큰·재귀 옵션은 호출 조건 탭으로), 토큰 합계 범위 선택(활성/상시 🔵)

- **1.2.0** — 항목 드래그 정렬 추가(데스크톱 사이드 목록 드래그, 모바일 정렬 모드), 기본 목록 드래그 정렬이 확장과 충돌해 끊기던 문제 수정
- **1.1.6** — 로어북 전환 시 항목 수/토큰이 어긋나거나 계산이 멈추던 문제 수정, 항목별 토큰 캐시 영속화로 재방문 시 즉시 표시
- **1.1.5** — 최초 공개 구조 (원문/번역 병렬 편집, 키워드 추천, 토큰 요약, 항목 내비게이터)
