# 로어북 매니저

SillyTavern 1.18용 로어북 UI 확장입니다. 기존 월드 인포 DOM과 저장 이벤트를 그대로 사용하고, 번역 편집기와 항목 탐색 UI만 추가합니다.

## 주요 기능

- 모든 SillyTavern 1.18 기본 로어북 기능 유지
- 원문/번역 병렬 편집
- 별도의 연결 프로필을 사용하는 번역 및 AI 편집
- 원문 변경 시 자동 번역
- 번역 변경 시 원문 자동 반영 또는 수동 반영
- 현재 로어북 전체 토큰 및 활성 항목 토큰 표시
- 데스크톱 항목 사이드 목록
- 모바일 상단 항목 선택창
- 원문, 호출 조건, 삽입/순서, 그룹/반복, 연결 필터 탭

임베딩과 AI 키워드 추천은 포함하지 않습니다. 해당 기능은 참로어와 중복되지 않도록 분리했습니다.

## 설치

압축을 해제한 `simple-lorebook` 폴더를 아래 위치에 넣고 SillyTavern을 새로고침합니다.

`SillyTavern/data/default-user/extensions/simple-lorebook`

AI 기능을 사용하려면 SillyTavern의 연결 프로필을 먼저 만들어야 합니다. 이 확장에서 선택한 프로필은 메인 채팅 연결 프로필을 변경하지 않습니다.
